# 研究材料说明

本目录用于复核报告，不是可直接安装运行的产品集合。

- `repository-snapshot.csv/json`：仓库身份、固定提交、抓取日期和元数据。
- `repos/<项目>/tree.txt`：该提交的完整文件目录。
- `repos/<项目>/files/`：采集的文档与按主题筛选的源码；不包含完整构建所需的所有文件。
- `repos/<项目>/manifest.json`：初次采集文件哈希；后补读取以相同固定提交为依据。
- `pages/*.txt` 与对应 JSON：成功采集的公开页面及来源信息；失败记录不能作证据。
- `review-core*.txt`：阅读辅助摘录，不是全文审计或运行测试。
- `review-log.json`：自动摘录脚本的运行记录；其中旧字段名含 reviewed 不应解释为逐行人工检查。
- `citations.csv/json`：正文使用的固定源码与页面引用。
- `external-references.csv`：正文全部外部链接。
- `catalog.json`：产品编号与章节映射。

脚本读取公开 GitHub 与官方页面，未执行第三方仓库代码。`collect_repos.py` 按固定提交建立目录和文件快照；`collect_pages.py` 保存网页文本；`render_references.py` 生成固定链接；`build_inventory.py` 生成清单。重新执行网络采集会访问外部公开站点，且不会保证得到原报告相同时间的内容。

报告中的作者分析、产品状态和模型建议应连同日期阅读。源码文件存在，只证明实现路径存在，不证明商业发布版默认启用或已经过本报告实测。
